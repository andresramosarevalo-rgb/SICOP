peticiones fallidas (http_req_failed 0 %).

DEF-06 (instrumento): el chequeo 'es el listado de empleados' falló en las 892 peticiones. El código de
respuesta fue 200 y las sesiones eran válidas, así que la causa probable es el propio chequeo: busca el texto
'Nomina/Empleados/Index' y el JSON de Inertia escapa las barras ('Nomina\/Empleados\/Index'). Mientras el
chequeo no se corrija, no hay evidencia automática de que cada respuesta fue el listado.
